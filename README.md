## 🌟 Proje Hakkında

Bu proje, geleneksel statik portfolyo sitelerinin ötesine geçerek **3D web grafiklerini** ve **dinamik içerik yönetimini** bir araya getiren üst düzey bir web deneyimidir. Kullanıcılara etkileşimli bir 3D sahne sunarken, arka planda çalışan **Özel Admin Paneli** sayesinde tüm içerikler kolayca yönetilebilir.

### 🎨 3D & Arayüz Özellikleri

- 🌀 **İnteraktif 3D Sahneler:** Three.js ve React Three Fiber altyapısıyla geliştirilmiş, mouse ve dokunma hareketlerine duyarlı 3D nesneler.

- ⚡ **Yüksek Performans & FPS:** Düşük donanımlarda dahi akıcı çalışan optimize edilmiş 3D render mimarisi.

- 🌙 **Lüks & Minimalist Arayüz:** Modern karanlık tema (Dark Mode) estetiği ve yumuşak geçiş efektleri.

- 📱 **Tam Responsive:** Tüm mobil, tablet ve masaüstü ekran boyutlarıyla kusursuz uyum.

### 🎛️ Yönetim (Admin) Paneli Özellikleri

- 📊 **Dinamik İçerik Yönetimi:** Projelerin, yeteneklerin ve iletişim bilgilerinin kod değiştirmeden paneller üzerinden güncellenmesi.

- 🔐 **Güvenli Kimlik Doğrulama:** Yetkisiz erişimleri engelleyen korumalı admin oturum altyapısı.

- ⚙️ **Anlık Veri Güncelleme:** Veritabanı entegrasyonu sayesinde arayüzde anında canlıya geçen değişiklikler.

## 🚀 Yerelde Kurulum ve Çalıştırma

```bash

# 1. Projeyi bilgisayarınıza klonlayın

git clone [[https://github.com/Ramazanutus0/ramazan-3d-portfolio.git](https://github.com/Ramazanutus0/ramazan-3d-portfolio.git)](https://github.com/Ramazanutus0/ramazan-3d-portfolio.git](https://github.com/Ramazanutus0/ramazan-3d-portfolio.git))

# 2. Proje klasörüne girin

cd ramazan-3d-portfolio

# 3. Gerekli bağımlılıkları yükleyin

npm install

# 4. Geliştirici sunucusunu başlatın

npm run dev
